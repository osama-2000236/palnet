Design contract

Preserve the field-row signature

Visual identity

Olive drives trust and selected state. Terracotta marks one decisive action. Warm paper and limestone layers hold dense professional content.

Typography

Arabic UI uses IBM Plex Sans Arabic; long Arabic body uses Noto Naskh Arabic. Numerals, handles, prices, and dates get explicit LTR treatment.

Interaction

Every mutation has loading, disabled, error, and success feedback. Web focus uses var(--focus-ring); mobile targets meet the shared minimum hit token.

Source files

packages/ui-tokens owns values. packages/ui-web and packages/ui-native own atoms. App routes own navigation and network behavior.

Non-negotiables

No LinkedIn blue, arbitrary hex, nested card soup, physical left/right CSS, unlabeled icon controls, placeholder production routes, or desktop flow without its mobile twin.

Composition

Same information architecture; native rhythm

Claude-ready prompt

Give this to the design platform with the repo

You are continuing Baydar (بيدر), an Arabic-first professional network in a pnpm Turborepo with Next.js 15 web and Expo 54 mobile. Read CLAUDE.md, AGENTS.md, .interface-design/system.md, and design-handoff-2026-06/README.md before proposing changes. Inspect the live repo; do not recreate existing work. Preserve Baydar's warm Palestinian professional identity: olive trust, parchment surfaces, ink typography, stone grouping, one terracotta commitment action. Never introduce generic LinkedIn/SaaS blue. For every flow, keep web and mobile hierarchy, language, states, and navigation consistent while respecting native interaction rhythm. Arabic RTL is primary; use logical CSS, LTR wrappers for numerals, visible focus rings, safe touch targets, and token values only. Reuse packages/ui-tokens, packages/ui-web, and packages/ui-native. App wrappers own navigation/network behavior. Pages/components stay under 300 LOC. Before editing, state the exact existing tokens and atoms you will reuse. After editing, verify loading, empty, offline, error, retry, disabled, success, Arabic RTL, English LTR, narrow mobile, desktop, keyboard, and touch. Run pnpm typecheck, pnpm lint, pnpm build, relevant Jest, and Playwright.
Artifact constraints: single HTML file, inline CSS/JS, no external requests, no backend, no external fonts or assets. Canonical production values remain in the repository token package.
