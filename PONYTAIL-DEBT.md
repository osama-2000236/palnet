# `ponytail:` debt ledger

Every deliberate shortcut in the codebase carries a `ponytail:` comment naming its ceiling
and, ideally, the trigger that says when to revisit. This file collects them so a deferral
can't quietly become permanent.

Generated by `/ponytail-debt` on 2026-08-01. Regenerate with:

```bash
grep -rnE '(#|//|--|/\*|\{/\*) ?ponytail:' . --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=docs
```

Rows tagged `no-trigger` name a ceiling but no upgrade path — those are the ones that rot
silently.

## apps/api

- `apps/api/src/modules/auth/auth.service.ts:116` — `updateMany` claim as the refresh-token
  race lock. **ceiling:** `count=0` means the race was lost, so all user sessions burn.
  **upgrade:** none named. `no-trigger`
- `apps/api/src/modules/billing/billing.service.ts:222` — UTC-day idempotency key plus the
  active-plan guard, instead of a DB constraint. **ceiling:** leans on nothing transitioning
  a subscription out of `ACTIVE`; two simultaneous requests still create two subscription
  rows against one debit. **upgrade:** a partial unique index on `Subscription` over
  `(userId, planId)` where status is `TRIALING`, `ACTIVE`, or `INCOMPLETE`.
- `apps/api/src/modules/billing/hyperpay.client.ts:65` — fail-closed webhook signature
  verification. **ceiling:** a missing secret rejects every webhook. **upgrade:** none named.
  `no-trigger`
- `apps/api/src/modules/jobs/jobs.service.ts:100` — folded `LIKE` prefilter for the jobs
  filter-as-you-type box. **ceiling:** sequential scan, fine at beta scale. **upgrade:** the
  folded FTS GIN index once the jobs table gets big.
- `apps/api/src/modules/jobs/job-alerts.service.ts:89` — full in-code scan of the alert table
  per new job. **ceiling:** beta scale. **upgrade:** move matching into SQL when alerts reach
  thousands.
- `apps/api/src/modules/messaging/messaging.service.ts:98` — transaction-scoped pg advisory
  lock, no pair-unique table. **ceiling:** MVP volume. **upgrade:** a pair unique table past
  MVP volume.
- `apps/api/src/modules/search/search.service.ts:336` — `INNER JOIN Company`, so a job with a
  null `companyId` is absent from search rather than wrong in it. **ceiling:** safe only
  while nothing can create such a job. **upgrade:** phase 4 (discovery) owns the fix — join
  the poster profile and `COALESCE` it in, or rename the field off "company". **Do not ship
  phase 5 before this.**

  Hermes, JS `console.*` goes to the Metro terminal and never reaches logcat, so JS warnings
  are invisible (verified 2026-07-26: a 38-screen run produced 38 empty `{}` files).
  **upgrade:** read Metro's own stdout instead; needs the harness to own the Metro process.
- `apps/mobile/src/lib/api.ts:37` — query-string cache buster. **ceiling:** the no-store

- `apps/mobile/src/lib/api.ts:56` — maps the network `TypeError` to `NETWORK_ERROR` at the

- `apps/mobile/app/(app)/composer.tsx:67` — email localpart as the author chip when the
